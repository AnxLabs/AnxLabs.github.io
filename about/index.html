Behind the projects

One machine became many directions.

AnxLabs is the umbrella for what I build: software, AI, games, infrastructure, development tools, and the experiments that don’t fit neatly into a category.

The extra “s” had a reason.

The name started with my original Anxlab machine / server. More projects followed, each pulling in a different direction: managing servers, working with AI, building game worlds, and making tools to help build the next thing.

AnxLabs became a name with enough room for all of them. The plural matters because the work was never going to stay in one category.

It’s still one builder following those threads. This site gives the work a front door.

A few guiding ideas

Build something. Learn something.

Useful foundations

Tools should solve real problems. A server control center, a voice assistant, and a terrain editor each begin with something concrete to make better.

Room to experiment

Some projects are in active development. Others are research or an early concept. They belong here with their stage clearly marked.

Keep the door open

The collection can grow into new software, models, plugins, hardware, or directions that haven’t been named yet.
